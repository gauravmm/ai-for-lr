Organisations may consider using different evaluation methods for different parts of the agentic
workflow (e.g. deterministic tests for structured tool calls vs LLM or human evaluation for
unstructured agent reasoning). However, there is still a need to evaluate agents holistically, so that
agent patterns across steps can be evaluated. Current industry solutions thus include defining
LLMs or agents to evaluate other agents, while incorporating human-in-the-loop review.29
