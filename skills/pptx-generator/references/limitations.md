# Template and engine limits

The package supports four source slide archetypes (`context`, `gate_focus`, `decision_summary`, `cover`) with text and existing bar shapes, one archetype per source slide in the template. It rebuilds the output by importing one source slide per plan slide (1-4 of them), so it does not edit a slide in place in a larger deck. Preserve the A*STAR Masterbrand theme and master in the source PPTX. Each source slide must contain every named shape described by `inspect`; complex content should live on source slides, not only in layouts.

Animations, embedded objects, unusual media, hyperlinks, extended charts, and relationship-bearing shapes are outside the allowlist. Editing such shapes may damage the package. Choose an approved archetype or have a human curate another template slide, then update the wrapper's allowlist and revalidate. The engine's published compatibility testing centers on PowerPoint 2019; test the actual distributed template in the target PowerPoint version before workshop use. The theme font is Open Sans; render parity depends on the Open Sans TTFs in `docgen/assets/fonts/` being installed wherever the deck is opened or rendered.

`validate` checks OOXML package structure, required shape names per slide, bounds, simple text capacity, semantic content, source notes, slide count against the plan, and PDF renderability when LibreOffice is available. It cannot prove visual legibility in every font environment or that a procurement claim is true. Review the rendered PDF at presentation size.
