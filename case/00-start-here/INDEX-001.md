## INDEX-001 §3 Using the bundle

INDEX-001 §3.1 — A document's status describes its role in the tender record. The signed grant and approved variation define project terms; the issued RFQ and formal addenda define tender requirements; each supplier's submitted schedules define its offer. Correspondence records questions and explanations. Evaluation workbooks, comparison tables and draft leadership outputs are analyses prepared from those sources. Record the document ID, clause or row and status when checking a claim.

INDEX-001 §3.2 — Some files have both a narrative preview and a structured companion such as a workbook or message file. They represent the same underlying packet but may expose different locators. For numerical checks, use the schedule row or workbook cell where available. The first recommendation is intentionally presented as working material for verification; it should be treated as a claim set to inspect, not as an approval record.
